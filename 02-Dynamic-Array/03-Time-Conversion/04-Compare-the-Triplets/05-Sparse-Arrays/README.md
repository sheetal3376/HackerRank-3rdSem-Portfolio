## Reflection
Through this activity, I improved my understanding of algorithmic problem solving and learned how to analyze the efficiency of different solutions. I practiced working with arrays, strings, matrices, nested sequences, and frequency-based searching. I also learned that writing a solution that produces the correct output is only one part of programming; choosing an efficient approach is equally important. Complexity analysis helped me understand the difference between solutions that require linear time and those that may require repeated iterations. Working with HackerRank also helped me become more comfortable with test cases, debugging, and submitting solutions through an online coding platform. Maintaining the solutions on GitHub helped me understand how developers organize and document their code for future reference. Overall, this activity strengthened my confidence in Python programming and problem solving and encouraged me to continue practicing algorithms regularly.
